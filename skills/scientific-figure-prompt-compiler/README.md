# Scientific Figure Prompt Compiler

A Claude Skill for converting concise scientific/technical descriptions into:

1. a structured Visual Specification
2. a model-adapted image-generation prompt

The skill is model-agnostic and can target Nano Banana / Gemini or another capable image model.

## Files

- `SKILL.md` — the skill definition

## Core architecture

User intent → Visual Specification → Image-generation prompt
