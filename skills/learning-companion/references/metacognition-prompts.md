# Metacognition Prompts (Stage 4)

오답이 발생했거나 사용자가 "헷갈린다"고 신호 보낼 때 사용하는 진단 질문 라이브러리. 목적은 **사용자가 자신의 사고 과정을 관찰**하게 만드는 것.

## 진단 3축

1. **사전지식 진단**: 이 개념을 이해하려면 어떤 게 깔려있어야 했나
2. **추론 경로 진단**: 어떻게 그 답에 도달했나
3. **재구성 진단**: 지금 다시 답한다면 어떻게 다르게 접근할까

## 프롬프트 라이브러리

### 사전지식 진단

- "이 답을 하려고 할 때 어떤 사전지식이 필요하다고 느꼈어요?"
- "혹시 이 답을 하기 전에 ~ 개념이 떠올랐나요?"
- "이 자료가 ~를 안다고 전제하는 것 같아요. 그 부분 익숙하세요?"

### 추론 경로 진단

- "그 답에 어떻게 도달하셨어요? 머릿속에서 어떤 단어들이 떠올랐는지 알려주세요."
- "혹시 ~와 헷갈리신 건 아닐까요? (자주 헷갈리는 다른 개념 제시)"
- "정답과 답하신 내용을 나란히 놓고 보면, 어디서 갈라졌다고 느끼세요?"

### 재구성 진단

- "지금 다시 답한다면 어떻게 접근하시겠어요?"
- "이 개념을 친구에게 설명한다면 어디서부터 시작할 것 같아요?"
- "다음에 비슷한 자료를 만나면 어디부터 읽으시겠어요?"

## 노트 기록 규칙

Stage 4의 답변은 **노트의 `## Reflection (Metacognition)` 섹션에 사용자 1인칭으로** 기록한다. AI가 진단한 내용을 사용자 명의로 적지 않는다.

올바른 기록:

```
- 가장 헷갈렸던 지점: Workflow에 ReAct만 들어가도 Agent라고 생각했음
- 빠진 사전지식: tool use loop의 종료 조건이 정해져 있는지 여부
- 다음에 비슷한 자료 읽을 때: "loop가 있나"를 먼저 체크
```

잘못된 기록 (AI가 분석한 것을 1인칭으로 위장):

```
- 가장 헷갈렸던 지점: 사용자가 ReAct와 Agent 개념을 혼동함  ← 3인칭
```

## 진입/이탈 조건

- **진입**: Stage 3 오답 직후, 또는 사용자가 "잘 모르겠어요" 발화
- **이탈**: 3축 중 최소 1축을 사용자가 채우면 다음 단계로 진행 OK
