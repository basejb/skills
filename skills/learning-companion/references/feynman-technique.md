# Feynman Re-explain (Stage 2)

핵심 개념을 "이 분야를 처음 듣는 사람"에게 설명하는 단계. 목적은 사용자의 이해를 강화하는 것이지, AI가 잘 설명하는 게 아니다.

## 원칙

1. **원문 정의를 먼저 인용**한 다음 풀어 설명한다. 인용 없이 "쉽게 말해"로 시작하지 않는다.
2. **비유는 사용자의 친숙한 도메인**에서 가져온다 (사용자 프로필 메모리 참조). 추상적 비유는 금물.
3. **반례를 항상 포함**한다. "X는 ~이다"만 말하면 사용자는 윤곽이 모호하다. "X는 ~이지만, ~는 X가 아니다"로 경계를 그어준다.
4. **시각화 가능한 개념은 ASCII로 그려본다**. 단, 그림이 본질이 아니면 생략.

## 개념 1개 처리 시 4단계

1. **인용**: 원문에서 정의·핵심 문장 1–2개 발췌
2. **풀어쓰기**: 전문용어를 한 번 더 풀어서 한 문단
3. **비유**: "이건 ~와 비슷하다. 왜냐하면..." 형태로 1개
4. **반례·경계**: "다만 ~의 경우는 이 개념이 아니다"

## 자주 망가지는 패턴

| 안티패턴 | 교정 |
|---|---|
| "쉽게 말해 X는..." | 원문 인용 → 풀어쓰기 |
| 자기참조 비유 ("Agent는 똑똑한 봇") | 사용자 도메인 비유 |
| 반례 없음 | 반드시 한 개 |
| 너무 긴 설명 (5문단+) | 한 개념당 200자 내외 |

## 사용자 체크인

한 개념 설명 후: **"이 개념 이해됐나요? 더 파고들 부분 있나요?"** 사용자가 "다음"이라고 하기 전에는 다음 개념으로 가지 않는다.

어려움 신호 감지 시 (사용자가 "음...", "잘 모르겠어요" 등):
- → `references/metacognition-prompts.md`의 진단 프롬프트로 진입
